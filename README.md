A make.fun one-line bounty entry: the funniest weather forecast for a city
that does not exist, in at most 120 characters.

> Port Nowhere: 22 degrees, clear skies, and a 60% chance the town exists by Thursday.

Run it with Node 22.18 or later:

```sh
node main.ts
```

The program writes the forecast line to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (or `out/` when the variable is unset).
